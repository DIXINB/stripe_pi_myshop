## stripe_pi_myshop  
### Назначение   
Это магазин, поддерживающий PaymentIntent технологию Stripe, которая намного более продвинута по сравнению с Checkout, использующей страницу, предоставляемую сервером Stripe. Помимо возможностей по кастомизации форм общения с клиентом, PaymentIntent предоставляет  различные способы оплаты и,кроме того, позволяет выполнять двухфакторную авторизацию. Это необходимо для проведения платежей в банках Европы и РФ.  
### Состав и запуск  
Должны быть установлены: Ubuntu 20.04, Python 3.10, Django 4. Также должны быть скачаны и установлены 2 пакета:  
  - celery, очередь заданий;
  - RabbitMQ, брокер сообщений. Получал я его в виде docker-образа, выполнив команду docker pull rabbitmq.
И ещё пара моментов:
  - перед запуском моего кода вам необходимо скопировать значения трёх ключей и версию Stripe из своего аккаунта своей учётной записи на облачном сервере. Для чего надо их создать, зарегистрировавшись. Проблем здесь нет. В тестовом режиме разрешено работать и из России. Значения ключей сохраняем в уже созданный мной файл .env в корневой папке;
  - также надо активировать интерфейс командной строки Stripe CLI,для чего перейти в папку stripe, где у меня уже есть скачанный исполняемый файл
и выпонить команду ./stripe login. После чего ещё пара шагов по подсказкам облачного сервера, с которым выполнится связь, приведут вас к результату Stripe CLI granted. Это значит, что интерфейс предоставлен.
