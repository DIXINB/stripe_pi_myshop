## stripe_pi_myshop  
### Назначение   
Это магазин, поддерживающий PaymentIntent технологию Stripe, которая намного более продвинута по сравнению с Checkout, использующей страницу, предоставляемую сервером Stripe. Помимо возможностей по кастомизации форм общения с клиентом, PaymentIntent предоставляет  различные способы оплаты и,кроме того, позволяет выполнять двухфакторную авторизацию. Это необходимо для проведения платежей в банках Европы и РФ.  
### Состав и запуск  
Должны быть установлены: Ubuntu 20.04, Python 3.10, Django 4. Также должны быть скачаны и установлены 2 пакета:  
  - celery, очередь заданий;
  - RabbitMQ, брокер сообщений. Получал я его в виде docker-образа, выполнив команду docker pull rabbitmq.
И ещё пара моментов:
  - перед запуском моего кода вам необходимо скопировать значения трёх ключей и версию Stripe из своего аккаунта своей учётной записи на облачном сервере. Для чего надо их создать, зарегистрировавшись. Проблем здесь нет. В тестовом режиме разрешено работать и из России. Значения ключей сохраняем в уже созданный мной файл .env в корневой папке;
  - также надо активировать интерфейс командной строки Stripe CLI,для чего перейти в папку stripe, где у меня уже есть скачанный исполняемый файл
и выпонить команду ./stripe login. После чего ещё пара шагов по подсказкам облачного сервера, с которым выполнится связь, приведут вас к результату Stripe CLI granted. Это значит, что интерфейс предоставлен. Этот шаг необходим именно в нашем случае, когда сервер магазина расположен у нас локально рядом с клиентом. Интерфейс Stripe CLI прослушивает появление нужного события из платежного шлюза Stripe и передаёт в локальную среду.
Хочу пояснить, что взаимодействие всегда идет между тремя объектами, это облачный Stripe сервер, наш сервер, на котором сайт, и клиент, т.е js код на девайсе пользователя. Алгоритм взаимодействия я возможно опишу отдельно вместе с описанием работы моего кода. Видео в этом README файле должно добавить понимания довольно сложной работы всего процесса.
Как выполнить запуск:
  1) Заходим в папку, где расположен сценарий запуска
     $cd stripe_pi_myshop/stripe_pi_myshop/ex_bash
  2) Определяем псевдоним запуска
     $alias stsh="gnome-terminal --window -- bash -c './e32'"
  3) Запускаем
     $stsh
### Порядок работы  
После запуска должно появиться 2 черных окна bash, на одном из которых будут 4 вкладки, в крайней правой которой в процессе работы магазина должен отображаться обмен с сервером Stripe, если все идет нормально. Эти два окна сами мгновенно свернутся и их место займет браузера, в котором вы будете совершать свою тестовую покупку. Этот процесс можно просмотреть в видео, расположенном ниже в этом файле.
